# Senales de urgencia veterinaria

Algunas senales requieren atencion veterinaria urgente.

Busca ayuda de inmediato si el perro tiene convulsiones.

La dificultad para respirar, respiracion muy agitada o encia azulada puede ser una emergencia.

El sangrado abundante o que no se detiene requiere atencion urgente.

La sospecha de intoxicacion por veneno, medicamentos, plantas, quimicos o alimentos peligrosos debe tratarse como urgencia.

La inconsciencia, desmayo o falta de respuesta requiere ayuda inmediata.

El vomito o diarrea severa, con sangre o persistente puede causar deshidratacion y debe revisarse pronto.

El dolor intenso, llanto constante, abdomen muy inflamado o incapacidad para caminar son senales de alarma.

Despues de un atropellamiento o golpe fuerte, el perro debe ser evaluado aunque parezca estable.

No des medicamentos ni dosis por tu cuenta. Contacta a un veterinario o servicio de urgencias.
